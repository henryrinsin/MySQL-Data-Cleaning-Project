# MySQL-Data-Cleaning-Project

Performing a data cleaning Project on World layoffs 2021-2023 datase

Project Overview

This project focuses on cleaning and preparing raw data using MySQL to improve data quality and ensure accurate analysis. The cleaning process involved identifying and correcting inconsistencies, removing duplicates, handling missing values, and standardizing data formats.

Data Cleaning Steps

1. Created a Working Copy of the Dataset

A duplicate table was created to preserve the original dataset before performing any cleaning operations.

2. Removed Duplicate Records

Duplicate rows were identified using unique identifiers and deleted to ensure data integrity.

3. Standardized Data Formats

Corrected inconsistent text entries.

Standardized date formats.

Trimmed leading and trailing spaces from text fields.

4. Handled Missing Values

Identified NULL and blank values.

Replaced or updated missing data where appropriate.

Flagged records requiring further review.

5. Corrected Data Inconsistencies

Fixed spelling variations and inconsistent naming conventions.

Standardized categorical values across the dataset.

6. Removed Unnecessary Columns

Columns that were irrelevant to the analysis were dropped to improve dataset efficiency.

7. Performed Final Validation

A final review was conducted to verify data accuracy, consistency, and completeness after cleaning.
